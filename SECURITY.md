# Security Policy

## Reporting a Vulnerability

**Do not open a public issue.**

Email: security@quantum-orchestrator.io

We aim to acknowledge reports within 48 hours and patch within 30 days.

## Supported Versions

| Version | Supported |
|---------|-----------|
| v1.x   | ✅ Yes    |
| v0.x   | ⚠️ Best-effort |

## Scope

- Operator binary and CRD API
- Provider adapters
- Transpiler sidecar
- Helm charts

Out of scope: upstream quantum SDKs, cloud provider services.
