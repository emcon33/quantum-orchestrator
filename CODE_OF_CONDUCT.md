# Code of Conduct

This project follows the [CNCF Code of Conduct](https://github.com/cncf/foundation/blob/main/policies-guidance/cncf-code-of-conduct.md).

## Our Standards

- Participate in good faith
- Use welcoming and inclusive language
- Be respectful of differing viewpoints and experiences
- Gracefully accept constructive criticism
- Focus on what is best for the community

## Reporting

Report violations to the CNCF Code of Conduct Committee:
[conduct@cncf.io](mailto:conduct@cncf.io)
